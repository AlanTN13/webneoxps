# Validación de categorías NexOps

Estas piezas son borradores de prueba. No se publican.

- Problemas / SEO: que nos encuentren por un problema real.
- Actualidad aplicada: traducir un cambio externo a una decisión empresarial.
- Criterio NexOps: mostrar cómo pensamos.
- Casos / Aplicaciones: hacer visible cómo llevamos una idea a operación.

Se crearán dos notas completas por categoría. La validación es simple: cada categoría debe sentirse distinta, aportar valor por sí misma y conectar con NexOps de manera natural.
